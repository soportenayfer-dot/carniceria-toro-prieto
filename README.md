
# Carnicería Toro Prieto

Aplicación móvil para la gestión y operación de una carnicería.

## Tecnologías utilizadas
- .NET MAUI
- C#
- XAML
- Firebase Authentication
- Firebase Realtime Database

## Descripción
Sistema móvil que permite gestionar productos, pedidos en línea y físicos, ventas, empleados y notificaciones.

## Plataforma
Android.
